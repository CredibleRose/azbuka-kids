# Весёлая Азбука

Мультяшное веб-приложение для детей 3–6 лет: русский алфавит (33 буквы) и английский (26), переключатель «АБВ / ABC».

- **Все буквы** — сетка цветных плиток; изученные буквы отмечаются звёздочкой.
- **Карточка буквы** — крупная буква (заглавная и строчная), картинка, слово с подсвеченной буквой, озвучка буквы и слова. Листать можно стрелками или свайпом.
- **Игры** (10 раундов, звезда за ответ с первой попытки):
  - «Найди букву» — услышать букву и нажать на неё;
  - «С какой буквы?» — посмотреть на картинку и выбрать первую букву слова.
- Маскот «Буквоша» — оригинальный персонаж, нарисован в SVG.

Озвучка — Web Speech API (голоса операционной системы), звуковые эффекты — Web Audio. Внешних зависимостей нет, кроме шрифта Nunito из Google Fonts (без интернета используется системный шрифт).

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 5178 --directory azbuka-kids
```

и откройте http://localhost:5178. Чтобы открыть на планшете в той же сети Wi-Fi, используйте IP компьютера вместо `localhost`.

Для английской озвучки нужен английский голос в системе (Windows: Параметры → Время и язык → Речь → Добавить голоса). В Chrome и Edge обычно есть встроенные онлайн-голоса.
